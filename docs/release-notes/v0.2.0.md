Sentry is now a desktop home for Google Drive: browse storage, upload and download files, manage sharing, and inspect local disk usage.

This release intentionally replaces the older Sentry Backup product in this repository. Its source remains on [backup/sentry-backup-before-drive-20260925](https://github.com/IEver3st/Sentry/tree/backup/sentry-backup-before-drive-20260925), at commit `deefaad998ea35630d17d599da547714fd2aa1fd`. No existing release tags or assets were removed.

The Drive app uses a different application identity (`com.ever3st.sentry`, previously `com.frommeans.sentry`). It does not migrate backup jobs, repositories, or credentials. If using Sentry Backup, stop its app/service and install this Drive app intentionally; preserve your backup data and old installation if you still need them. Older builds using this repository's update feed may discover this replacement.

- Fixed the startup and reopen loading regression caused by losing renderer readiness during navigation.
- Reduced hidden-window event delivery and automatic UI work while keeping transfers running.
- Fixed scan-worker cleanup and bounded metadata concurrency.
- Added GitHub release updates and Windows x64 installer verification.

Google Drive connection uses a Desktop OAuth client imported in Settings. The Windows installer is unsigned. Full upgrade/download/install/relaunch verification and live Google transfer performance remain unverified.
