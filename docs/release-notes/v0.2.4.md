Sentry now refreshes the affected folders when a batch move or trash action stops partway through.

Previously, if one item succeeded and a later item failed, the view could keep showing the old state until another refresh. Successful changes now appear even when the remaining items cannot be processed. The original failure is still reported.

This release includes the multi-drive storage map from v0.2.3. Local drives and folders work without an account. Optional Google Drive access requires your own Google Cloud Desktop OAuth client; a shared, verified sign-in client is not included.

The Windows x64 installer is unsigned. Downloads, the update manifest, and SHA-256 checksums are attached to this release.
